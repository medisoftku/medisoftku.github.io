#Medisoft
A storefront website designed for simple purchasing and delivery of swords, armor, chain mail, and cooking pots.
<img width="553" height="761" alt="image" src="https://github.com/user-attachments/assets/19c1f1c5-808b-4e85-887d-6dd3e77a0151" />

#Features
-The site features customer reviews on the home page
<img width="276" height="182" alt="image" src="https://github.com/user-attachments/assets/01a7959e-832f-4f29-a75e-2da1716ff28a" /><br>
-A catalog the user can browse for their desired item(s), called "catalogue" for time appropriate language
-A cart system that tracks what a user has in their cart, including local storage to remember the cart's contents
-Checkout menu that charges the user for their order
-BONUS FEATURE: Checkout includes a delivery option with different dialogue and an added delivery fee

#AI Usage
-There is no AI generated code in the website
-AI did play a role in the teaching of JavaScript and providing helpful resources for learning how to implement specific functions needed in the JavaScript portion of the website
